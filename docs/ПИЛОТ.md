## 2. Схема интеграции

```
Данные города                         Ядро ПРЕДЕЛ                         Потребители
─────────────                         ───────────                         ───────────
управление образования:               чистые функции TypeScript           КМГИС (Geometa):
  мощность, контингент   ──┐          (src/model), без интерфейса    ┌──> слой нагрузки GeoJSON
БАРС / Реформа ЖКХ:          │                                        │
  жители домов           ──┼─ CSV ──> проект + район + сценарий ──────┼──> 3D-макет ЦГТ
ЦОДД: детекторы          ──┤  GeoJSON  → 11 лет × 3 состояния         │
ИСОГД: разрешения, ППТ   ──┘  (этап 2:  → мероприятия, P10–P90        └──> отчёт PDF к согласованию ППТ
                               REST)
```

- Этап 1 (пилот): обмен файлами CSV/GeoJSON, ПРЕДЕЛ работает как статический сайт в контуре ЦГТ.
- Этап 2: HTTP API ядра (п. 4 бэклога), вызов из КМГИС.
- Персональные данные не нужны: агрегаты по учреждениям и домам.
- Координаты WGS84; МСК-16 — перепроекция на входе и выходе (п. 5).
- Воспроизводимость: «Сохранить сценарий» фиксирует проект, коэффициенты и мероприятия в одном файле.

## 3. Программа пилота

- **Цель:** проверить точность прогноза на данных Казани и применимость к проектам на согласовании.
- **Площадка:** один район по выбору ЦГТ. Уже собраны Ново-Савиновский (прогноз из 2021 года сверен с фактом 2026)
  и Советский (Азино, проверка на построенных ЖК); по 7 районам и городу есть «Графики».
- **Данные от ЦГТ:** мощность и контингент школ и садов района; жители домов; 3 ЖК, введённых в 2018–2022 гг., с датой
  разрешения на строительство; 2–3 проекта на согласовании; детекторы ЦОДД — по возможности.
- **Допуски:** обмен файлами без персональных данных; соглашение о конфиденциальности — по требованию ЦГТ.
- **Роли:** ЦГТ — ответственный за пилот и поставщик данных (назначает ЦГТ); ООО «НейроКонтур» — руководитель пилота
  Андрей Лебедев, разработчик и аналитик.
- **Календарь:** октябрь — данные ЦГТ и ретро-проверка 3 ЖК; ноябрь — калибровка долей детей и поездок, расчёт проектов;
  до 30.11 — отчёт.
- **Метрики успеха:**
  - ошибка прогноза контингента школ и садов на ретро-проверке — цель ≤ 15% (порог согласовать с ЦГТ);
  - у 100% показателей — источник, статус и диапазон;
  - пересчёт сценария — меньше 1 с;
  - 2–3 проекта рассчитаны с перечнем мероприятий.
- **Результат:** отчёт о ретро-проверке, расчёты проектов (PDF и GeoJSON), откалиброванные коэффициенты, отзыв ЦГТ.
- **Стоимость пилота:** по согласованию.
